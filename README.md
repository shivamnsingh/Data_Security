# Data Security Practicals

Install deps with `pip install -r requirements.txt`, then run any file, e.g. `python practical_01_aes_encryption.py`.

| # | File | What it shows |
|---|---|---|
| 1 | `practical_01_aes_encryption.py` | AES (ECB) encrypt / decrypt |
| 2 | `practical_02_des_encryption.py` | DES (ECB) encrypt / decrypt |
| 3 | `practical_03_rsa_encryption.py` | RSA-OAEP encryption / decryption |
| 4 | `practical_04_ecdh_key_exchange.py` | ECDH shared-key agreement |
| 5 | `practical_05_ecdh_man_in_the_middle.py` | ECDH broken by a man-in-the-middle |
| 6 | `practical_06_hashing_md5_sha1.py` | MD5 and SHA-1 hashing |
| 7 | `practical_07_hmac_tamper_detection.py` | HMAC detecting a tampered message |
| 8 | `practical_08_digital_signature.py` | RSA digital signature sign / verify |

`TYDS_Social_Media_Analytics_Assignment.pdf` is the related assignment.

Educational code only.
